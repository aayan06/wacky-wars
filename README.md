# Wacky Wars 🛸

A gallery shooter game built with Phaser 3.

## How to Play
- **A** - Move left
- **D** - Move right
- **Spacebar** - Shoot

## About
Fight off waves of hand-drawn wacky alien invaders before they reach you. 
Dodge enemy bombs, rack up your score, and survive as long as you can!
